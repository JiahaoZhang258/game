# 借鉴对方算法的公平实验报告

## 1. 实验口径

本实验不覆盖正式结果文件。问题2的所有候选均使用同一份附件、同一评价期（2025-02-01至2025-12-31）、同一实际一月物理预热轨迹，并从共同的1月末储电量开始。预测函数只读取决策日前已完成的数据，未使用目标日及之后的实际值。

共同的2月1日初始储电量为10800 kWh，来自当前固定参数下的一月物理预热。所有费用均含计划购电、紧急购电及适用的调整费用，一月费用不计入2--12月总额。

本实验沿用当前已确认的区间终点口径：0:10对应0:00--0:10。对方Excel采用非时间顺序的列排列，但标签与对应数据一起移动，不能仅凭列顺序不同就判定其费用无效；实验不复制其导出布局。

这是固定借鉴配置的历史比较，不按2--12月费用重新选参，也不是未接触过的独立测试。对方结构已经经历全年探索，不能因局部参数曾用一月校准就把整个研发过程称为仅使用一月。实验结果不自动升级为正式策略。

## 2. 问题2逐项消融

| 方案 | 借鉴负荷预测 | 借鉴光伏预测 | α | ρ | 计划日末固定2400 | 总费用/元 | 相对当前/元 | 紧急购电量/kWh |
|---|---|---|---:|---:|---:|---:|---:|---:|
| 当前方案 | 否 | 否 | 0.800 | 0.050 | 否 | 13,723,786.52 | 0.00 | 115,260.30 |
| 仅借鉴光伏趋势 | 否 | 是 | 0.800 | 0.050 | 否 | 13,725,094.49 | +1,307.97 | 119,164.85 |
| 借鉴负荷+光伏预测 | 是 | 是 | 0.800 | 0.050 | 否 | 13,693,020.49 | -30,766.02 | 113,810.01 |
| 再加入风险参数 | 是 | 是 | 0.825 | 0.625 | 否 | 13,687,995.24 | -35,791.28 | 103,533.69 |
| 再加入日末硬SOC=2400 | 是 | 是 | 0.825 | 0.625 | 是 | 13,671,164.37 | -52,622.14 | 98,978.21 |

结果表明：

1. 21天光伏趋势单独使用没有带来收益，反而增加约1308元费用。它降低了计划购电费，但增加了紧急购电费。
2. 对方的同星期负荷均值与光伏趋势组合后，费用下降约3.08万元。
3. 将误差分位数提高到0.825、储能保护比例提高到0.625后，费用进一步下降约0.50万元，紧急购电量明显减少。
4. 加入日末储电量硬约束后，费用再下降约1.68万元，达到约1367.12万元。该方案与对方问题2的预测、参数和控制结构基本一致，但仍保留了我们的物理一月预热和2月1日高SOC初值，因此比对方原始报告的1367.34万元低约0.23万元。

α是历史预测误差的分位数水平，用于给预测净需求加上风险余量；ρ是保留储电量的比例，用于决定当期最多放出多少电。2400 kWh是预测计划的日末储电量约束，不是把实际电池每天重置。联合方案实际年末储电量为2543.99 kWh，高于当前方案的1309.75 kWh，因此费用下降不是靠额外耗尽年末库存获得的。逐项贡献依赖上述替换顺序，不能视为互不影响的独立贡献。

## 3. 问题3复现性消融

以下结果来自对方问题3实现本身的复现，统一将2月1日初始SOC改为我们的物理一月末SOC，仅用于判断其组件作用，不能直接替代当前问题3正式结果。

| 对方问题3组件 | 总费用/元 | 紧急购电量/kWh |
|---|---:|---:|
| 当前正式问题3（不同模型结构） | 14,013,224.10 | 218,248.23 |
| 借鉴预测和参数，但不允许日内调整 | 13,741,048.19 | 176,443.67 |
| 加入6:00、12:00、18:00调整 | 13,276,973.35 | 54,862.61 |
| 只加入6:00调整 | 13,543,063.89 | 113,848.78 |
| 只加入12:00调整 | 13,499,600.24 | 119,167.21 |
| 只加入18:00调整 | 13,344,821.47 | 87,782.38 |

联合方案相对当前问题3少736250.75元，约5.25%。在对方实现内部，三个更新时间相对不调整下降约46.41万元。这验证了该策略下允许日内调整的整体收益，但还不能分离出下列每一项的贡献：

- 附件3预报与历史趋势融合；
- 每次规划到日末，但只提交和执行下一次发布前的6小时区间；这是滚动时域控制，不能把优化时域也说成只有6小时；
- 问题3借鉴配置为混合比例0.5、误差分位数0.7、保护比例0.625，计划日末目标2400 kWh。分位数0.7与问题2的0.825不同，不能笼统说两问都更保守；
- 当前正式问题3在每次预报发布后也会重算未来计划，所以没有证据证明“只提交6小时”单独解释了相对当前方案的全部下降。

关闭更新时刻同时改变了可用预报和交易机会；本次8组更新时间比较不能独立衡量新增预报信息本身的价值，也不用于回头选择表现最好的更新时间组合。

## 4. 结论与采用建议

建议优先借鉴并进一步验证：

- 同星期负荷均值预测；
- 21天光伏趋势预测，但不能单独采用，应与其他预测融合；
- 光伏历史预测与附件3预报的融合；
- 问题2的`alpha=0.825`、`rho=0.625`，与问题3的融合比例0.5、`alpha=0.7`、`rho=0.625`分别验证；
- 显式日末SOC目标2400kWh；
- 问题3的预测误差修正、预报融合和滚动调整机制作为联合候选继续验证。

暂不直接采用：

- 对方一月待机、2月1日固定从6000kWh开始的状态口径；
- 对方result2.xlsx和result3.xlsx的非时间顺序列布局；这是布局差异，本身不造成已核算费用下降；
- 未在相同时间口径下重新导出的对方Excel。

本实验结果保存在 `q2_borrowed_algorithm_experiment.json` 和 `q2_borrowed_algorithm_experiment.csv`。正式方案尚未被替换。

问题3更新时间消融的完整结果保存在 `q3_borrowed_update_ablation.csv`。该表使用对方问题3实现、共同的1月物理预热末SOC和同一评价期；它是组件作用实验，不是对当前问题3正式代码的直接重算。`borrowed_experiment_validation.json`记录了物理约束、指定边界扰动和正式文件未被修改的验证结果。
