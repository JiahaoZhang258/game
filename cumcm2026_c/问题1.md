# 问题1　典型日计划购电策略

## 1. 问题分析与建模约定

问题1要求：在电价、小区负荷每日相同，并已知当天光伏发电功率预测的条件下，于每日 0:00 制定全天计划购电策略，使微网供电不低于小区负荷，且储能在 0:00 与 24:00 的储电量相同，同时尽可能降低购电费用。

本问属于**完全信息下的确定型日前调度**。电价、负荷与光伏预测在决策时刻全部已知，不存在预测误差，也没有紧急购电与违约调整。因此不必对不确定性作简化，可直接在 10 分钟分辨率上建立精确的功率平衡与储能模型。需要事先明确的，只是题面未写死、但求解所必需的若干约定：

1. **时间对齐。** 附件1给出 144 个采样点，时间标签为 `0:10, 0:20, …, 23:50, 0:00+1`，与结果模板中的区间 `0:10–0:20, …, 0:00+1–0:10+1` 逐行对应。本文将时间戳视为区间**起点**，每个时段长度 \(\Delta t=10/60=1/6\) 小时，覆盖完整的 24 小时循环日。功率（kW）与电量（kWh）的换算为 \(E=P\Delta t\)。

2. **储能效率与功率口径。** 附录给出充放电效率 90%、最大充放电功率 5000 kW。本文取充电、放电效率各为 \(\eta=0.9\)（往返效率 81%），5000 kW 限制加在与微网母线交换的交流侧功率上。为避免过充过放，储电量始终限制在 \(1200\sim 10800\) kWh。

3. **能量流向。** 题面只计购电费用、未给出上网电价，故不允许向外部电网售电；光伏余电只能充电或弃光。购电功率不设上限。因 \(\eta<1\)，同时充电与放电会无谓损耗，最优解中二者不会同时为正，建模时不必引入 0–1 变量。

4. **储电量初值与日循环。** 附录给定 2025 年 1 月 1 日 0:00 储电量为 6000 kWh，故第一天从 6000 kWh 起步。题面要求每天 0:00 与 24:00 储电量相同；天数衔接上，次日 0:00 即当日 24:00，于是午夜储电量将一直保持 6000 kWh。白天各时段储电量仍是自由决策，只需落在 \(1200\sim 10800\) kWh。

在上述约定下，决策量为各时段计划购电、储能充放电（以及必要时的弃光）；目标为全天购电费最小。这是标准的带储能经济调度问题，约束均为线性，可用线性规划一次求得全局最优。

## 2. 数学模型的建立

将一天离散为 \(T=144\) 个时段，记 \(t=1,2,\ldots,T\)。已知量为时段 \(t\) 的电价 \(p_t\)（元/kWh）、负荷功率 \(P^{\mathrm{L}}_t\)（kW）与光伏预测功率 \(P^{\mathrm{PV}}_t\)（kW）。决策变量如下（除储电量外均以 kW 计，且非负）：

- \(P^{\mathrm{buy}}_t\)：向外部电网的计划购电功率；
- \(P^{\mathrm{ch}}_t,\,P^{\mathrm{dis}}_t\)：储能充电、放电功率（交流侧）；
- \(P^{\mathrm{curt}}_t\)：弃光功率；
- \(E_t\)：时段 \(t\) 结束时的储电量（kWh），\(E_0\) 为 0:00 储电量。

**目标函数**为全天购电费用最小：

\[
\min \quad \sum_{t=1}^{T} p_t\,P^{\mathrm{buy}}_t\,\Delta t. \tag{1}
\]

**功率平衡。** 微网供电不得低于负荷，余电以弃光吸收，故写成等式

\[
P^{\mathrm{buy}}_t + P^{\mathrm{PV}}_t + P^{\mathrm{dis}}_t = P^{\mathrm{L}}_t + P^{\mathrm{ch}}_t + P^{\mathrm{curt}}_t, \qquad t=1,\ldots,T. \tag{2}
\]

**储能动态与箱约束**

\[
E_t = E_{t-1} + \eta P^{\mathrm{ch}}_t\Delta t - \frac{P^{\mathrm{dis}}_t\Delta t}{\eta}, \qquad t=1,\ldots,T, \tag{3}
\]

\[
1200 \le E_t \le 10800, \qquad 0 \le P^{\mathrm{ch}}_t \le 5000, \qquad 0 \le P^{\mathrm{dis}}_t \le 5000. \tag{4}
\]

**初值与日循环**

\[
E_0 = 6000, \qquad E_T = E_0. \tag{5}
\]

另有 \(P^{\mathrm{buy}}_t\ge 0\)，\(P^{\mathrm{curt}}_t\ge 0\)。式 (1)–(5) 构成线性规划。该规划可行域为凸多面体，目标为线性，数值求解得到的是全局最优计划购电策略。

下面从能量守恒、电价套利和对照实验三方面说明该解是合理的。

**（1）能量账闭合，物理约束均起作用。**  
若不计储能损耗，净负荷电量为 \(111024.81-55482.84=55541.97\) kWh。循环运行下充电与放电满足

\[
\eta\sum_t P^{\mathrm{ch}}_t\Delta t = \frac{1}{\eta}\sum_t P^{\mathrm{dis}}_t\Delta t = 18666.60~\mathrm{kWh},
\]

交流侧损耗为 \(20740.67-16799.94=3940.73\) kWh。于是

\[
55541.97 + 3940.73 = 59482.70~\mathrm{kWh},
\]

与全天购电量精确一致；弃光为 0，说明光伏全部被负荷或储能消纳。储电量在一日内既触及下限 1200 kWh 也触及上限 10800 kWh，表明可用容量被用满；充、放功率在谷段与部分午间贴紧 5000 kW。最优解中任意时段均不同时充放。这些都说明约束是紧的、可行的，并非数值噪声。

**（2）调度形态符合峰谷套利常识。**  
附件1电价呈典型峰谷：约 22:00–6:00 为谷（约 0.42–0.45 元/kWh），11:00–13:00 出现第二个低价窗口（最低约 0.41 元/kWh），18:00–21:00 为晚峰（最高 1.395 元/kWh）。往返效率 0.81 对应的盈亏电价比约为 \(1/0.81\approx 1.23\)，而晚峰/谷电价比约 2.9，远高于盈亏比，因此应当谷充峰放。最优轨迹正是这一形态：

- **夜间谷电充电。** 因午夜必须停在 6000 kWh，22:00 后只充到 6000，0:00 之后再继续充；凌晨在更低电价处补满至 10800 kWh。相对“午夜可停在 8550”的方案，只是把同一批谷电从 22:00–24:00 挪到了 0:00–2:00。
- **早峰只放不购。** 约 6:00–9:00 用电价高峰，负荷缺口全部由放电满足，购电为 0。
- **午前高价不向电网加购。** 10:00–10:10 光伏已大于负荷，但电价仍高（约 1.00 元/kWh），故只将余光充入储能，表 1 中该时段购电量为 0。
- **午间低价连同余光满充。** 11:00–13:00 电价落到约 0.44 元/kWh，仅靠余光不足以在晚峰前把储电量重新抬满，因此短暂向电网加购并贴着 5000 kW 充电。这就是 12:00–12:10 出现 486.40 kWh 购电的原因：该时段购电功率约 2918 kW，与光伏余电一并打满充电功率。14:00 电价已回升，停止加购。
- **晚峰前“囤电”、峰中放电。** 16:00–18:00 电价尚未到顶，先按净负荷购电、电池不动；19:00–20:30 进入最高价窗口后全力放电，故 20:00–20:10 购电为 0。储电量约在 20:40 落到 1200 kWh，其后只能购电，22:00 再进入下一轮谷充。

同一 4 小时统计窗内同时出现充电量与放电量（例如 8:00–12:00、20:00–24:00），是因为窗内前半与后半电价方向相反，并非同一时刻对冲。

**（3）对照表明费用下降来自储能；午夜取 6000 几乎不损失最优性。**  
若完全不用储能、余光在无法就地消纳时弃掉，只按 \(\max(P^{\mathrm{L}}_t-P^{\mathrm{PV}}_t,0)\) 购电，全天购电费约为 48052.05 元。引入储能后降至 35126.95 元，节约 12925.10 元（约 26.9%），与“把谷电和午间余光搬到早晚高峰”的机制相符。

若取消 \(E_0=6000\)、只保留 \(E_T=E_0\) 并优化午夜电量，最优午夜为 8550 kWh，购电费 35118.60 元，仅少 8.35 元（0.024%）。表 1 六个指定时段完全不变，白天 6:00–21:00 轨迹重合，差别只在夜间充电时段平移。因此：真正决定费用的是峰谷搬移是否用满 9600 kWh 可用容量。采用“第一天 6000 + 每日首末相同”既对接附录初值，又几乎不损失经济性。

若只固定 \(E_0=6000\) 而放开 \(E_{24}\)，最优会在晚峰把电放到 1200 kWh，费用降到约 32910 元——这是在消耗库存，次日无法按同一典型日重复，不符合题面“0:00 与 24:00 储电量相同”，故不采用。

综上，问题1的计划购电策略由线性规划全局最优给出，能量守恒、峰谷逻辑与对照实验三者一致，结果可用于后续问题的基准。
